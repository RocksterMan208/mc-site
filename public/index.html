How to connect to the server

To connect to the server you must first download the modpack (if there is one; if there is, follow instructions in "Download section"). You will then need to launch the game and then go into "Multiplayer" on the main menu. From this point you can either decided to do "Direct Connection" or "Add Server". For adding the server, in the name section put any sevrer name you wish, as it is unimportant to joining the server, then in the address section you must put the server IP address which is shown above.


You should now be done and now able to connect to the server successfully. Any new mods added will be in a separate section of downloads where you will be able to download the newest "batch" of mods added.

That's set up done.
